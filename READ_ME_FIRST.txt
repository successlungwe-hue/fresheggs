FRESHEGGS - WINDOWS .EXE AND ANDROID .APK BUILD KIT
===================================================
fresheggs_python\            the web app + build_exe.bat (makes FreshEggs.exe)
                             + run_for_phone.bat (server for the Android app)
fresheggs_android_app\       Android Studio project (makes the .apk)

WINDOWS .EXE  (needs Windows with Python 3.10+)
  1. Open fresheggs_python and double-click build_exe.bat
  2. Wait a few minutes. Result: fresheggs_python\dist\FreshEggs.exe
  3. Double-click FreshEggs.exe: it opens the shop in your browser.
